# TOT Insights document archive

Large primary-source files for [TOT Insights](https://totinsights.org), served from this repository's GitHub Pages site so the main site stays inside GitHub Pages' 1 GB limit.

Browse and search these files from the hub, not here: each collection has a page on totinsights.org that lists, describes and embeds them.

## Collections

| Folder | Hub page | Files |
|---|---|---|
| `occupied-museums-acts/` | [DOC-183, Official acts on the museums of occupied Ukraine, 2014 to 2026](https://totinsights.org/primary-sources/occupied-museums/doc-183.html) | 176 PDFs (4 further acts in the set are hosted on the main site) |
| `security-acts-occupied/` | [DOC-193, Russian security law in the occupied territories](https://totinsights.org/primary-sources/rf-security-law/doc-193.html) | 59 PDFs: federal martial-law, security and property acts, and acts of the occupation authorities (official texts from publication.pravo.gov.ru and the Zaporizhzhia and Kherson regional portals) |
| `mariupol-admin-2026/` | [DOC-194, Mariupol administration decrees, May 2026](https://totinsights.org/primary-sources/mariupol-admin-2026/doc-194.html) | 9 PDFs: decrees Nos. 918 to 960 of the Mariupol occupation administration |

`occupied-museums-acts/` was compiled by CURIA Lab (Cultural Resilience Informatics and Analysis), University of Virginia, November 2026. `INDEX.csv` and `README.txt` are CURIA Lab's index and notes, unchanged. Acts of the occupation authorities are filed under the names those authorities use for themselves; that describes the source and does not recognise it.

## Adding a collection

Put the files in a new top-level folder, commit and push to `master`. Pages publishes the folder at `https://totinsights.github.io/tot-insights-archive/<folder>/...`. Link or embed those URLs from the hub page.
